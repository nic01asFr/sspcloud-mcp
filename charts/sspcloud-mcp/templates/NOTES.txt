{{- $host := .Values.app.host -}}
{{- $base := printf "https://%s" $host -}}
{{- $garde := .Values.appAuth.token -}}
### SSPCloud MCP est lancé

- Santé du service : [ouvrir]({{ $base }}/health)

Le serveur est un Deployment Kubernetes : redémarrage automatique, jamais
auto-suspendu. Il survit à la fermeture des pods Jupyter.

### URL du connecteur (copier-coller)

Collez cette adresse dans Claude : Paramètres → Connecteurs → Ajouter un
connecteur MCP.

```
{{ $base }}/mcp
```

{{- if $garde }}

Clé API (à saisir au formulaire OAuth, ou en-tête Authorization) / password: {{ $garde }}
{{- else }}

La clé a été tirée au sort au déploiement. Pour la lire :

```
kubectl get secret {{ include "sspcloud-mcp.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.PASSERELLE_MCP_BEARER}' | base64 -d ; echo
```
{{- end }}

### Config MCP Claude Code / Cursor (copier-coller)

{{- if $garde }}

```json
{
  "mcpServers": {
    "sspcloud-mcp": {
      "type": "http",
      "url": "{{ $base }}/mcp",
      "headers": { "Authorization": "Bearer {{ $garde }}" }
    }
  }
}
```
{{- else }}

```json
{
  "mcpServers": {
    "sspcloud-mcp": {
      "type": "http",
      "url": "{{ $base }}/mcp",
      "headers": { "Authorization": "Bearer <clé API>" }
    }
  }
}
```
{{- end }}

**Alternative** — Claude Desktop / mobile / claude.ai : connecteur personnalisé,
URL `{{ $base }}/mcp`, clé API une fois au consentement OAuth.

Pour arrêter : Mes services → supprimer, ou
`helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}`
(la clé Bearer est conservée — annotation resource-policy: keep).
