Un poste de calcul SSPCloud, piloté par votre assistant IA.

SSPCloud MCP donne à Claude (Desktop, mobile, Code) un poste de travail distant sur le datalab : pousser un dépôt, exécuter du code, exploiter le GPU, des notebooks à état persistant, et déployer des services — le tout depuis la conversation, dans votre namespace.

Installer le service Installer avec un agent IA
# Dans un terminal d'un service SSPCloud lancé en rôle « edit » curl -sf https://gitlab.cerema.fr/mcp/sspcloud_mcp/-/raw/main/charts/sspcloud-mcp/scripts/install.sh | bash

Le problème

Un assistant IA sait écrire du code, mais pas l'exécuter sur une vraie machine. Dès qu'il faut un GPU, un notebook ou un traitement lourd, la conversation s'arrête sur un « lancez-le vous-même depuis l'interface ». Le datalab SSPCloud offre pourtant du calcul gratuit — il manquait le pont.

Ce que ça fait

Deux verbes, à distance, sur la vraie infra du datalab.

▶

Exécuter du code

Kernel Python à état persistant (variables, modèle GPU en mémoire) + shell : git, pip, pytest dans le pod.

◆

GPU arbitré

Un slot GPU par utilisateur, bascule par projet avec préemption ; l'environnement de chaque projet préservé (PVC).

≣

Notebooks complets

Créer, exécuter, itérer un .ipynb ; le collègue rouvre le même fichier dans son JupyterLab.

↥

Déployer un service

Exposer une API ou une démo en HTTPS depuis la conversation. 24 outils MCP au total.

Durable & sécurisé

Un service « produit », pas un bricolage qui tombe.

∞

Durable

Le serveur est le process principal d'un Deployment Kubernetes : redémarrage automatique, jamais auto-suspendu, survit à la fermeture des pods.

⚿

OAuth navigateur

Connecteur MCP OAuth 2.1 + DCR + PKCE (avec CORS) pour Claude Desktop, mobile et claude.ai. Ou header statique pour Claude Code / Cursor.

◱

Mono-namespace

Chacun installe son service dans son namespace. Clé bearer auto-générée, jamais connue de l'auteur. Aucun accès aux données d'autrui.

Installer

Deux voies — la plus simple arrive en un clic depuis le catalogue Onyxia.

Catalogue Onyxia (recommandé). Catalogue → sspcloud-mcp → Lancer. Le service apparaît dans « Mes services », rôle et URL réglés tout seuls.
CLI durable. Depuis un pod lancé en kubernetes.role: edit, une commande (ci-dessus) crée le Deployment durable et affiche votre clé.
Connecter Claude. Collez l'URL …/mcp dans un connecteur ; au formulaire OAuth, saisissez la clé. Les 24 outils apparaissent.
